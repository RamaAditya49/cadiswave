# OpenWave 1.2.0

OpenWave 1.2.0 adds dedicated XLR Dock MK.2 support and includes installation, audio-routing and interface fixes since 1.1.1.

## XLR Dock MK.2

- Added a separate profile and vendor-protocol backend for the Elgato XLR Dock MK.2 (`0fd9:00c7`), addressing [#6](https://github.com/rikkichy/openwave/issues/6). It is not an alias of the `00a6` profile.
- Implemented microphone gain, mute and 48V phantom power; headphone volume and low-impedance mode; and hardware monitor mix, with Dock-specific control ranges.
- Detects the supported control bank using read-only requests. Writes remain disabled if neither bank supplies the required configuration blocks. Control updates preserve unrelated bytes and write only changed blocks.
- Added capture-device identification and USB permission rules for `00c7`.
- Software tests and GTK checks passed, but this backend has not been physically tested with a Dock MK.2 by the OpenWave maintainer. Onboard DSP controls are not included.

## Installation and audio fixes

- Run the installer's pinned Rust toolchain through `rustup run` ([#29](https://github.com/rikkichy/openwave/pull/29)).
- Improve migration of legacy Python launchers that do not explicitly name their module ([#30](https://github.com/rikkichy/openwave/pull/30)).
- Preserve all filter-chain modules when writing effects configuration for PipeWire ([#28](https://github.com/rikkichy/openwave/pull/28)).
- Release unrecorded application streams from OpenWave-owned sinks before unloading those sinks during shutdown ([#36](https://github.com/rikkichy/openwave/pull/36)).

## Interface improvements

- Added a **Reload interface** application-menu action ([#35](https://github.com/rikkichy/openwave/pull/35)).
- Improved mixer-card padding and row alignment, gave master sliders the same minimum width as source sliders, and moved add buttons into the matrix corner ([#31](https://github.com/rikkichy/openwave/pull/31), [#33](https://github.com/rikkichy/openwave/pull/33), [#34](https://github.com/rikkichy/openwave/pull/34)).
- Prevented the autostart switch from echoing its own snap-back as another operation ([#32](https://github.com/rikkichy/openwave/pull/32)).

Thanks to [@NyleGarcia](https://github.com/NyleGarcia) for the installation, routing and interface fixes above.

## Upgrade notes

- Dock MK.2 users need the updated administrator-managed USB rule for `0fd9:00c7`; see [host setup](https://github.com/rikkichy/openwave/blob/v1.2.0/docs/install-bazzite.md).
- Native packages target x86-64 Linux: Ubuntu 24.04, Debian 13 and Fedora 43. The prepared source archive and Arch recipe are also provided. Flatpak remains experimental and is not a native host-setup substitute.
- Configuration remains under `${XDG_CONFIG_HOME:-~/.config}/openwave`. Back it up before upgrading; use the existing package manager or documented manual installation workflow.
